Concepts clés : Nœuds et Liens

Analogie simple : un nœud = une ville · un lien = une route.

Les nœuds sont les personnes, les téléphones ou les lieux.
Les liens sont les appels, les SMS ou les rencontres.

Concepts clés : Centralité

Un nœud central est celui qui a le plus de liens directs.

Attention : ce n'est pas forcément le chef. Ça peut être un standardiste, un commercial, ou un membre de la famille.

❓ Si je retire ce nœud central, que se passe-t-il ? (cliquez)
Les autres nœuds ne communiquent plus entre eux. Le réseau se fragmente.

Concepts clés : Intermédiarité

Un nœud intermédiaire relie deux groupes qui ne se parlent pas directement.

Analogie : c'est le facteur qui apporte le courrier entre deux villages.

❓ Quel est le rôle de ce nœud (P) dans le réseau ? (cliquez)
Il est le pont entre les deux groupes. Sans lui, la communication est coupée.

Concepts clés : Clusters

Un cluster est un groupe de nœuds très connectés entre eux, mais peu connectés aux autres.

Attention : un cluster peut être une famille, une équipe de travail… ou une cellule criminelle.

L'analyse SIM-Terminal

Une SIM peut changer de terminal. Un terminal peut changer de SIM.
Il faut suivre les couples IMEI ↔ IMSI dans le temps.

Individu Événement Détail
R Changement de SIM IMEI …671 : SIM …001 → …004 (11/03)
X Changement de terminal IMEI …699 → …888 (12/03 à 22h00)
Anomalie Partage de terminal IMEI …699 (X) a aussi utilisé la SIM …003 (S) à 22h10
⚠ Un changement de SIM n'est pas une fraude en soi. Il doit être expliqué (perte, vol, ou brouillage volontaire).

L'exercice pratique

Mission : Vous êtes analystes. Vous avez le graphe du réseau et le fichier SIM-Terminal. Votre mission : identifier 3 hypothèses sur les rôles et 3 anomalies techniques. Vous avez 2 heures.
  • Sous Gephi : Importer les fichiers et appliquer le layout ForceAtlas2.
  • Calculer la centralité (degré et intermédiarité).
  • Sous Excel : Remplir la matrice SIM × Terminal.
  • Rédiger 3 hypothèses et 3 anomalies.

✓ Synthèse automatique (indices, pas des preuves)

  • Le nœud le plus central est Z (coordinateur).
  • L'intermédiaire X est le pont entre Z et R.
  • L'anomalie majeure est le changement de terminal de X juste avant l'interception.
  • Attention : ces observations sont des indices, pas des preuves.

Conclusion — 3 messages à retenir

1

La centralité n'est pas la culpabilité.

2

Un changement de SIM n'est pas une fraude.

3

Un cluster n'est pas un groupe criminel.

Toujours croiser les données, contextualiser, et formuler des hypothèses prudentes.
